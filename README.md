# Flipped Energy developers

Build software, connect AI agents and automate your home using your own Flipped Energy account.

| Guide | Use it for |
| --- | --- |
| [Customer API](customer-api/README.md) | Read account, billing and usage data or perform supported account actions |
| [MCP](mcp/README.md) | Give an AI client access to your account tools |
| [Homebridge](iot/homebridge-flipped-energy/README.md) | Apple Home signals and Eve energy history |
| [Home Assistant](iot/home-assistant/README.md) | Sensors, automations and the Energy dashboard |
| [M5Stack](iot/m5stack/README.md) | ESP32 Matter devices and an energy display |

Start in the [account developer portal](https://flipped.energy/accounts/developer?tab=tokens). Sign in, enable APIs and MCPs, and create a token for your integration. Use read-only access when you only need to read data. Keep the token private and replace it before it expires.

The website hosts the current [API reference](https://flipped.energy/accounts/developer?tab=reference), [interactive tester](https://flipped.energy/accounts/developer?tab=tester) and [MCP setup tools](https://flipped.energy/accounts/developer?tab=mcp). These guides link to those tools so endpoint definitions, examples and limits stay in one place.
