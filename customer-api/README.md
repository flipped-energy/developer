# Customer API

The customer API lets your own software access the accounts belonging to your Flipped Energy login. It covers billing, meter usage and supported account actions.

1. Create a token in the [Tokens tab](https://flipped.energy/accounts/developer?tab=tokens). Choose read-only for data access, or read and write for account changes.
2. Find an operation in the [live API reference](https://flipped.energy/accounts/developer?tab=reference).
3. Run it in the [API tester](https://flipped.energy/accounts/developer?tab=tester), then copy the generated code into your application.

The live reference documents authentication, endpoints, request and response formats, limits and errors. Keep tokens on your own server or trusted device; do not embed them in a public site or distributed application.
