# Home Assistant

The [Flipped Energy integration](https://github.com/flipped-energy/home-assistant) supplies tariff and price signals for automations and imports metered usage into Home Assistant's Energy dashboard.

Follow the [installation guide](https://github.com/flipped-energy/home-assistant#readme), create a [read-only token](https://flipped.energy/accounts/developer?tab=tokens), then add Flipped Energy under Settings → Devices & services. Select the account and meter when prompted. Integration options control virtual switches and spot-price visibility.

See the [live API reference](https://flipped.energy/accounts/developer?tab=reference) for the underlying account and usage data.
