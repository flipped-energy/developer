# M5Stack Core2 for AWS

The officially supported Core2 for AWS is a touchscreen energy display and Matter device, with LED indicators for tariff and optional wholesale-price signals.

Follow the [Core2 setup guide](https://github.com/flipped-energy/m5stack/tree/main/m5stack/coreaws), install the Core2 firmware, pair it with your Matter controller, then use the on-screen token setup flow with a [read-only token](https://flipped.energy/accounts/developer?tab=tokens).

The device settings control screen and LED brightness. Use the account website's [usage page](https://flipped.energy/accounts/usage) for the full interactive usage view.
