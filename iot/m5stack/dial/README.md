# M5Stack Dial

The officially supported M5Stack Dial provides a compact round display with rotary input for Flipped Energy data and Matter signals.

Follow the [Dial setup guide](https://github.com/flipped-energy/m5stack/tree/main/m5stack/dial) for the board-specific firmware and Wi-Fi commissioning steps. Supply a [read-only developer token](https://flipped.energy/accounts/developer?tab=tokens) when configuring your account.

Use firmware built specifically for the Dial; Core2 images target different hardware.
