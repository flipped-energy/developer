# MCP for AI agents

The Flipped Energy MCP server exposes customer API operations as tools for an MCP-capable AI client. Tools act with the access granted by your token.

Open [MCP for agents](https://flipped.energy/accounts/developer?tab=mcp) in your account. Select a token and follow the live instructions for your client; the page supplies its connection URL or configuration. A read-only token is suitable for questions about your account, invoices and energy usage.

Use the [API reference](https://flipped.energy/accounts/developer?tab=reference) to understand the operations behind the tools. Revoke a token from [Tokens](https://flipped.energy/accounts/developer?tab=tokens) when you no longer want a client to have access.
